# Files

- [Command line and connect console](cli-and-console.md) - The termdeck command line (profile management, connect, tunnel, sftp, ports, forget-host, and launching the TUI, web and desktop UIs), its console, batch and password-file prompters and exit codes, and console.py which runs `termdeck connect` interactively with a Ctrl+] escape or as a byte-exact pipe like ssh/plink.
- [Desktop GUI (pywebview)](desktop-gui.md) - How `termdeck gui` wraps the web UI in a pywebview window — the web server on a background thread, WebView2 detection on Windows, the minimal exposed JS API, close confirmation while sessions are connected, window size persistence in logical pixels and the system-theme background.
- [Textual TUI](tui.md) - The default `termdeck` interface — a Textual app with a profile sidebar and quick connect, terminal tabs each driven by a SessionController and rendered with pyte, a profile editor generated from describe_options(), modal prompter dialogs, menu keys behind a Ctrl+] escape, and an SFTP file panel.
- [Web UI server and front end](web-ui.md) - The local aiohttp server behind `termdeck web` and the desktop window — localhost-only Host/Origin checks, one-time start tokens exchanged for per-tab secrets, the JSON/binary terminal WebSocket protocol driven by SessionController, WebPrompter, profile and SFTP REST endpoints with single-use download tickets — and the xterm.js single-page front end.
