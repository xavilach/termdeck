# Files

- [Profile storage and private files](profile-store.md) - How ProfileStore keeps profiles in one versioned JSON file with cross-process locking, atomic replacement and lossless handling of invalid entries, and how config.py places termdeck's data and creates owner-only files on POSIX and Windows.
- [Profiles and the option registry](profiles-and-options.md) - How a termdeck Profile and its SSH, serial and terminal sections are declared once with option() metadata, validated with OptionError naming the faulty field, described to UIs by describe_options(), and how quick targets like bob@host:2222 or COM3@9600 become unsaved profiles.
- [SessionController: tab connection lifecycle](session-controller.md) - controller.SessionController is one tab's connection in the TUI and web UI — its connecting/connected/failed/ended state, capabilities (break, SFTP, typing), reconnects that re-read the saved profile, epoch-based cancellation of stale connects, close-on-exit and the JSON snapshot every UI renders.
- [Sessions and TerminalSession](sessions.md) - The Session byte-stream ABC and Prompter protocol every UI implements, open_session, and TerminalSession — the layer that applies a profile's terminal settings (charset, CR/LF, remote filtering, printer capture, line editing, echo, answerback), bounded output backpressure, session and SSH packet logs, and error classification.
- [Terminal byte processing, line editing and themes](terminal-processing.md) - The shared terminal helpers in vt.py (key remapping, initial modes, the RemoteFilter that enforces "remote may …" options, printer capture, bell limiting, title and paste cleaning, printable logs), the local LineEditor for devices without a line editor, and the colour themes in themes.py.
