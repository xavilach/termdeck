# Files

- [Proxies and proxy commands](proxies.md) - How termdeck reaches an SSH server through a proxy — when the profile's proxy applies (exclusion patterns, local hosts), the SOCKS 4/4a, SOCKS 5, HTTP CONNECT and PuTTY-style Telnet proxy handshakes, local proxy commands, jump-host commands, and how each plugs into asyncssh as a tunnel object.
- [Serial transport and USB device identity](serial.md) - How termdeck opens serial ports with pyserial (any device or rfc2217/socket/loop/cp2110 URL), runs reader and writer threads with backpressure and write timeouts, sends breaks and keeps DTR/RTS stable, and how a profile records a USB adapter's identity to follow it when its COM port name changes without ever guessing between adapters.
- [SFTP file transfer](sftp.md) - The core SFTP class that shares one lazily opened channel per SSH connection and implements listing, safe uploads via temporary files, downloads without copying dangerous modes, resumable transfers, chmod parsing and Windows-unsafe name checks — and the three front ends built on it, the psftp-like `termdeck sftp` command, the TUI files panel and the web SFTP API.
- [SSH transport](ssh.md) - How termdeck's SSH transport (ssh.py, on asyncssh) builds a connection from a profile — username, authentication methods and password changes, host key verification against termdeck's known_hosts with confirmation, pinning and revocation, algorithms, jump hosts and proxies — then opens port forwards and a shell, command, subsystem or forwards-only session, shares connections between tabs, and reports exit statuses and errors.
